The transformation is essentially the inverse of the view-projection matrix, but leaving the homogeneous (translational) parts zero. Essentially, the texture matrix is: $$\mathbf{M}_\text{tex} = (\mathbf{P}\mathbf{V})^{-1} = \mathbf{V}^{-1}\mathbf{P}^{-1}$$ Except that the translational parts are set to zero, as we're only interested in rotation for the “skybox”.
