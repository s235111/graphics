a) Flat, Gouraud, and Phong Shading

Flat shading calculates lighting only once for each face, using the same colour for the entire face, causing edges to appear sharp. This kind of shading works well if those hard edges are desired, when shading a cube for example, but produces undesirable results for objects that are supposed to appear smooth, such as a sphere.

Gouraud shading calculates lighting information per vertex and interpolates the resulting colour across the face. As lighting is calculated per vertex, vertex normals can be used, and edges can be made to look smoother. This technique does produce visible artifacts, though, especially with specular highlights.

Phong shading uses the same principle as Gouraud shading, but calculates lighting information per fragment instead. Instead of the resulting colour, vertex normals are interpolated across faces. This drastically improves the visual quality of the lighting, again especially for specular highlights.

One way to do flat shading would be to not share vertices between faces, instead giving each face its own set of vertices where all the normals are that of the face. This wouldn't by itself make each face only consist of one colour, only if no specular highlights or distance falloff is used. I'm not sure if there's a way to calculate lighting information per face and not per vertex, given how the rendering pipeline is set up.

Based on my results, Phong shading definitely produces better results for specular highlights as well as for diffuse lighting.

b) Directional and Point Lights

A directional light has no position, only a direction. This means only the orientation of a surface matters in terms of how it gets lit. A point light has a position, but doesn't point in any particular direction. Surfaces are lit depending on their orientation relative to this position as well as the distance to it. A directional light can be thought of as a light at infinity with no distance falloff. The point light position essentially becomes the direction of the directional light.

c) Eye Position

The eye position only affects the shading of objects in terms of the highlights. Ambient and diffuse lighting don't depend on the position of the observer.

d) Setting Specular to Zero

Setting the specular term to $(0,0,0)$ essentially turns off specular highlights, meaning only ambient and diffuse lighting are in effect. As described above, this means the eye position no longer changes how the object is shaded.

e) Increasing Shininess

Increasing the shininess exponent causes the specular highlight to become “narrower”, making the surface appear more glossy.

f) Coordinate Space

I used world space for calculating lighting.
