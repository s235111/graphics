Filtering

There are two filtering modes, nearest neighbour and linear.

For textures, nearest neighbour filtering simply chooses the closest texel, resulting in a sharp but pixelated look. Linear filtering does linear interpolation between the closest texel values, which reduces the pixelation but can cause a very blurry look instead.

Minification is the mode to use when a fragment covers more than one texel, and magnification is the mode to use when a texel covers more than one fragment. The mipmap filtering mode affects the blending between mip levels. Nearest-neighbour chooses a specific mip level and samples just that, potentially causing sharp seams to appear where the mip level changes. Linear filtering instead interpolates between the two nearest mip levels, resulting in a smoother transition.
