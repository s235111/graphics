Instead of calculating a look-at point, I've added a lookAngles function to MV.js which takes a yaw and pitch in degrees. It calculates the sin and cos of each angle and uses those to directly construct the three orthogonal vectors. This is more efficient and avoids the issue with the view vector and up vector aligning.

If for some reason you wanted to, this also allows you to look beyond 90° up/down if you remove the clamping, viewing the world upside down like you would if you tilted your head all the way back.
